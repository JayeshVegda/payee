PAYEE PAYMENT LEDGER - DEVELOPMENT SETUP

Requirements
- Node.js 24.x
- pnpm 11.18.0

Setup on the new PC
1. Extract this ZIP.
2. Open PowerShell or a terminal in the extracted folder.
3. Enable pnpm if needed:
     corepack enable
     corepack prepare pnpm@11.18.0 --activate
4. Install dependencies:
     pnpm install --frozen-lockfile
5. Build the application:
     pnpm run build
6. Create and migrate a fresh local database:
     pnpm run db:migrate
7. Add the included demonstration data:
     pnpm run db:seed-demo
8. Start development mode:
     pnpm run dev

Open http://127.0.0.1:4782 in your browser.

Notes
- Dependencies, generated build output, logs, backups, and the current local
  database are intentionally not included in this source archive.
- Copy .env.example to .env only if you need to override the default settings.
- See README.md and the docs folder for architecture and product documentation.
